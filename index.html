常見問題 FAQ

資料會同步到我的其他裝置嗎？
會。登入同一個 iCloud 帳號後，歌曲與歌單會透過你的私人 iCloud 自動同步，離線時也能完整使用。
怎麼把歌曲分享給團員？
在歌曲或歌單上點「分享」，用 AirDrop 或訊息傳送；對方用 Ostinato 開啟檔案即可匯入。
AI 辨識需要付費或 API 金鑰嗎？
在支援 Apple Intelligence 的裝置上不需要。你也可以在設定中改用自己的 OpenAI API 金鑰。
